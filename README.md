# Prompts and proof

A self-contained, 19-slide presentation of prompt-to-proof work in Scope and ProTour. Open `index.html` locally or at the deployed site. Use arrow keys or swipe to advance.

It includes named skill invocations where supported by redacted visible chat exports; pstack and non-pstack skills are not conflated. Source artifacts, commit links, and evidence limits appear on the slides. ProTour chat cards are typeset excerpts, not native chat screenshots. The Sol/Grok run described here was isolated from `main`.
