# Prompts and proof

A self-contained, 14-slide presentation of prompt-to-proof work in Scope and ProTour. Open `index.html` locally or at the deployed site. Use arrow keys or swipe to advance.

Source artifacts, commit links, and evidence limits appear on the slides. The ProTour chat cards are typeset excerpts from redacted visible chat exports, not native chat screenshots. The Sol/Grok run described here was an experiment isolated from `main`.
